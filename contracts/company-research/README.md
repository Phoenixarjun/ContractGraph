# Company Research Contract Bundle

## Purpose

This bundle defines the desired outputs for a Claude Code-native graph workflow. It does not contain company data. Claude Code researches and produces node outputs; deterministic validation checks each node against its contract before it can be accepted.

## Source of truth

- `contract.bundle.json` defines the bundle, roles, ownership, aggregation, and global rules.
- `node-contracts/*.contract.json` are valid JSON Schemas and node contracts.
- `contract.schema.json` validates the final merged report.
- `graph.yaml` is a generated reference graph and may be regenerated by `/contractgraph:init`.
- `policies.json` controls model use, evidence, freshness, retries, privacy, and token efficiency.

## Important design choices

- HLD, LLD, DSA, behavioral, CS fundamentals, and other domains are workflow nodes, not framework primitives.
- Company intelligence owns authoritative company facts.
- Company initiatives owns public projects and technical programs.
- Role intelligence owns role and job requirements.
- Profile alignment is the shared anti-duplication hub.
- Resume analysis evaluates all configured roles and one or more resumes.
- Every research node emits local sources; the deterministic merger builds the global source registry.
- Every candidate claim must reference canonical context.
- Every material public claim must reference evidence.
- Structural schema validation is necessary but not sufficient; semantic and evidence verification are mandatory.
